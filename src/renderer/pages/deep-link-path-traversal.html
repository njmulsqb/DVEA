Deep Link → Path Traversal

Deep link reads an arbitrary file path supplied by the attacker.

Route: Arbitrary File Read

Some apps accept deep links that open files. If the main process reads the supplied path with no validation, an attacker can craft a deep link that reads sensitive host files.

Objective: Read a file outside the app's intended directory via a crafted deep link.

Demo

Enter a file path and click "Simulate Deep Link". The demo invokes the same vulnerable main-process file-read path and displays the returned contents.

Use the bundled src/renderer/pages/secret.txt to demonstrate traversal reliably.
