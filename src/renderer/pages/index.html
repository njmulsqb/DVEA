What Can XSS Do in Electron?
The same injection, three configurations, three very different blast radii — the same unsanitized innerHTML injection across three window configurations, escalating from browser-equivalent XSS to full remote code execution.
Challenge 1 — Contained: hardened config; XSS is walled to the renderer Challenge 2 — Bridged: correct isolation, one overprivileged preload API Challenge 3 — Owned: main process evaluates renderer input with full Node access
Stored HTML Injection → IPC Token Exfiltration
A stored display name is rendered via innerHTML in an analytics window. A <meta http-equiv="refresh"> payload bypasses CSP and redirects the window to an attacker page that calls an unvalidated IPC bridge to steal the session token.
HTML Injection CSP Bypass IPC
